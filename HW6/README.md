## 단계 ③ 답
선형 회귀는 수량과 단가의 가중합이라 곱셈을 표현하지 못한다. qp=수량×단가를 추가하면 총액 공식을 표현해 R²가 1.0이 된다.
## 단계 ⑤ 결정과 이유
깊이 8을 선택한다. 교차검증 평균이 0.992로 깊이 12의 0.995와 차이가 작고, 잎 수는 250개로 781개보다 적다.
## 단계 ⑦ 답
API에는 선형 회귀+qp를 사용한다. 예측이 실제 총액 8,000,000원과 같고, 깊이 8 트리는 7,362,301원으로 예측한다.
